# Datos locales

- `datos_formularios.json`: paciente actual, borradores y última planilla seleccionada.
- `profesionales.json`: perfiles profesionales y firmas cargadas.
- `signatures/`: imágenes de firma conservadas del proyecto anterior.
- `examples/`: archivos de datos de ejemplo conservados del proyecto anterior.

Estos archivos son locales y están excluidos de Git. La aplicación crea los JSON cuando se guardan datos. Para conservar pacientes, borradores y perfiles al trasladar el proyecto, copiar también esta carpeta.
